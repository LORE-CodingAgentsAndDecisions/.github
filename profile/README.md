# LORE: Coding Agents and Decisions

Master's research at the [University of Antwerp](https://www.uantwerpen.be/en/) on how coding agents keep track of decisions that change across sessions.

> **When coding agents make decisions across many sessions, and those decisions keep changing, how does each session know which decisions still hold?**

- **Research project (RQ1):** how well do existing context strategies, such as context files, summaries, retrieval and memory systems, keep coding agents on the decisions in force?
- **Master's thesis (RQ2):** can a decision memory, which tracks decisions, their rationale and how they change, do better, and which of its properties make the difference?
