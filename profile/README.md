# LORE: Coding Agents and Decisions

Master's research at the [University of Antwerp](https://www.uantwerpen.be/en/) on how coding agents keep track of decisions that change across sessions.

The research question, documents and research logs are on the [**website**](https://lore-coding-agents-and-decisions.arnedepeuter.workers.dev).

Datasets will be published on [**Hugging Face**](https://huggingface.co/LORE-CodingAgentsAndDecisions).
